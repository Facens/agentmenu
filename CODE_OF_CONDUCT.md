# Code of Conduct

This is a small project with one maintainer. There is no committee and no
formal enforcement ladder — there's Andrea Giannangelo, reading what comes
in.

## What's expected

Disagree with the code, the design, or a decision as directly as you like —
that's normal for a project like this. Don't make it personal, don't harass
another commenter, and don't turn an issue or a pull request thread into
something that has nothing to do with the project.

## What happens if you don't

A comment that crosses that line gets deleted. A thread that stays hostile
gets locked. An account that keeps doing it gets blocked from the
repository. None of that runs through a process with steps or an appeal —
it's one person deciding what belongs on their own project.

A closed pull request is not a conduct decision. Scope and the licence grant
a contribution has to carry are covered in
[CONTRIBUTING.md](CONTRIBUTING.md); a PR that doesn't fit is closed for
those reasons, however politely it was written.

## Reporting

Say so in the issue or pull request itself, or mention `@Facens` directly.
There is no separate address for this — the project doesn't have one, and
inventing one nobody's actually watching would be worse than not having it.
